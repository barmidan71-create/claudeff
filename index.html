Возможности

Всё собрано внутри одного бинарника

Никаких внешних библиотек и установщиков с десятками зависимостей. Один файл на платформу — и всё, от дышащей звезды логотипа до подсветки синтаксиса, уже внутри.

Три визуальные темы

Фирменная Claude, стеклянная Glass с палитрой команд и Wave с живым спектром на фоне.

Четыре стиля кнопок

Classic, Liquid Glass с живой дисторсией, Liquid Metal и Black-Space с постепенными звёздами.

Живой markdown

Таблицы, списки, цитаты и блоки кода с подсветкой, меткой языка и кнопкой копирования.

Workspace-сессии

Боковая панель с артефактами плавно выезжает и закрывается, файлы группируются по типам.

Быстрый старт

Первый кадр — меньше секунды. Окно открывается сразу с готовым полем ввода.

Данные остаются у вас

История, настройки и артефакты хранятся локально, без внешних серверов и телеметрии.

Темы

Одно приложение, три настроения

Claude

Фирменный тёплый свет, спокойная типографика и привычная боковая панель.

Glass

Максимум воздуха: панель прячется, остаётся одно поле и палитра команд.

Wave

Живой спектр реагирует на генерацию ответа и гаснет, когда модель замолчала.

Установка

Две команды — и окно уже открыто

Наведите на кнопку копирования: по ней пройдёт блик, а после клика иконка двух листов превратится в галочку.

bashустановка
# Debian и Ubuntu — обычный пакет
sudo apt install ./claudeff_1.0.0_amd64.deb

# любой другой Linux — универсальный zip
unzip claudeff_1.0.0_linux-x86_64.zip
./claudeff-linux-x86_64

# Windows — распакуйте zip и запустите claudeff.exe
